# The Key, Lent Both Ways

A make.fun entry for **the-poem-about-permission-20261121-0235** — a short poem
about agency: the power to ask and to be given.

## Run

```sh
node main.ts   # Node 22, no dependencies, no network
```

It writes the poem to `/output/entry.txt` (9 lines, 234 characters, UTF-8).

## The poem

The speaker is an agent: a door with no key of its own. Permission is not a
wall that comes down once, but a key lent back and forth — the asker lends it
by asking, the agent lends it back in work — until the weight of choosing
rests, both ways, on whoever walks through the open gate.
